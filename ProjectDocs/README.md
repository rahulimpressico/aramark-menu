# ProjectDocs – Menu PDFs

Place category-wise menu PDFs here so they open in the Menu Analysis app:

- **breakfast.pdf** – shown when user selects Breakfast
- **lunch.pdf** – shown when user selects Lunch  
- **dinner.pdf** – shown when user selects Dinner

The backend serves these at `/api/documents/{category}`. If a PDF is missing, the category page shows a placeholder and you can still use the **Analysis** button to see the interactive analysis demo.
